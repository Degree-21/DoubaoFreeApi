# Doubao API Monitor 浏览器插件

这个浏览器插件用于监听豆包聊天请求并提取会话数据。

## 功能特性

1. **用户信息存储**: 允许用户输入并存储手机号和名称
2. **快速跳转**: 一键跳转到豆包聊天页面
3. **请求监听**: 自动监听 `/samantha/chat/completion` API 请求
4. **数据上报**: 将监听到的请求数据上报到指定的后端接口

## 安装方法

1. 打开 Chrome 浏览器，进入扩展程序管理页面 (`chrome://extensions/`)
2. 开启右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择此 `browser-extension` 文件夹
5. 插件安装完成

## 使用方法

1. **配置用户信息**:
   - 点击浏览器工具栏中的插件图标
   - 输入手机号和名称
   - 点击"保存信息"

2. **开始监听**:
   - 点击"打开豆包聊天"按钮，或手动访问 https://www.doubao.com/chat/
   - 插件会自动监听聊天请求
   - 监听到的数据会自动上报到后端

## 监听的数据

插件会捕获以下信息：
- 请求URL和参数（特别是 `aid` 参数）
- Cookie 信息
- 请求头信息
- 时间戳
- 用户代理信息

## 配置上报地址

默认上报地址为 `http://localhost:8001/api/monitor/report`

如需修改，请编辑 `content.js` 文件中的 `reportingUrl` 变量。

## 文件结构

```
browser-extension/
├── manifest.json          # 插件清单文件
├── popup.html             # 弹出页面HTML
├── popup.js               # 弹出页面逻辑
├── content.js             # 内容脚本
├── injected.js            # 注入脚本（页面级别）
└── README.md              # 说明文档
```

## 注意事项

1. 插件只在豆包官网 (doubao.com) 上运行
2. 需要用户先保存手机号和名称才能正常上报数据
3. 请确保后端接口能够接收 JSON 格式的 POST 请求
4. 插件会在浏览器控制台中输出监听日志

## 隐私说明

此插件仅在用户使用豆包聊天时监听相关API请求，不会收集其他网站的数据或个人隐私信息。所有数据仅用于指定的业务目的。
